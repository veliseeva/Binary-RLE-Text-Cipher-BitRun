# 🔐 Binary RLE Text Cipher (BitRun)

![Python](https://img.shields.io/badge/Python-3.6%2B-blue.svg)
![Dependencies](https://img.shields.io/badge/Dependencies-None-brightgreen.svg)

Легковесный инструмент на Python для кодирования и декодирования текста. Скрипт переводит текст в бинарный код (UTF-8), а затем сжимает последовательности нулей и единиц по принципу RLE (Run-Length Encoding) в буквенно-цифровой шифр, разбитый на пары символов.

> **Примечание:** Технически это алгоритм *кодирования и обфускации*, а не криптографического шифрования. Он отлично подходит для скрытия текста от беглого взгляда, головоломок (CTF) или просто для развлечения.

## ✨ Особенности

* **Поддержка любых символов:** Благодаря использованию UTF-8, скрипт корректно работает с кириллицей, латиницей, иероглифами и даже эмодзи (🚀, 🐍).
* **Zero-dependencies:** Используется только стандартная библиотека Python (`re`).
* **Контроль целостности:** Декодер проверяет валидность введенных символов и кратность восстановленного бинарного кода 8 битам, защищая от повреждения данных.
* **Два режима работы:** Можно использовать как интерактивную консольную утилиту или импортировать функции в свой проект.

## ⚙️ Как это работает?

Алгоритм состоит из 4 шагов при кодировании (и обратных при декодировании):

1. **Перевод в бинарный код:** Весь текст кодируется в поток бит UTF-8 (по 8 бит на каждый байт).
2. **Группировка (RLE):** Подряд идущие единицы (`1`) и нули (`0`) группируются в серии (максимум по 8 штук в одной группе).
3. **Замена по словарю:**
   * Серии из **`1`** (от 1 до 8 штук) заменяются на буквы от **`A`** до **`H`**.
   * Серии из **`0`** (от 1 до 8 штук) заменяются на цифры от **`1`** до **`8`**.
4. **Форматирование:** Полученная строка разбивается пробелами на блоки по 2 символа.

### Таблица замены:
| Биты (`1`) | Символ | Биты (`0`) | Символ |
| :--- | :---: | :--- | :---: |
| `1` | **A** | `0` | **1** |
| `11` | **B** | `00` | **2** |
| `111` | **C** | `000` | **3** |
| `1111` | **D** | `0000` | **4** |
| `11111` | **E** | `00000` | **5** |
| `111111` | **F** | `000000` | **6** |
| `1111111` | **G** | `0000000` | **7** |
| `11111111` | **H** | `00000000` | **8** |

**Пример разбора буквы `A` (латиница):**
1. Бинарный код UTF-8: `01000001`
2. Разбивка на серии: `0` + `1` + `00000` + `1`
3. Замена по таблице: `1` + `A` + `5` + `A`
4. Итог: **`1A 5A`**

## 🚀 Использование

### 1. Интерактивный режим (CLI)
Просто запустите скрипт в терминале:

```bash
python main.py
```

**Пример сессии:**
```text
Выберите действие (encrypt / decrypt) или exit: encrypt
Введите текст: Привет
Результат: B1 A4 A2 G1 A3 B7 B1 A4 A1 C3 B1 A4 A1 B2 A1 B1 A4 A1 B1 A1 C1 A3 B6 A1

Выберите действие (encrypt / decrypt) или exit: decrypt
Введите текст: B1 A4 A2 G1 A3 B7 B1 A4 A1 C3 B1 A4 A1 B2 A1 B1 A4 A1 B1 A1 C1 A3 B6 A1
Результат: Привет

Выберите действие (encrypt / decrypt) или exit: exit
```

### 2. Использование в качестве модуля
Вы можете импортировать функции `encrypt` и `decrypt` в свой собственный код:

```python
from main import encrypt, decrypt

secret = encrypt("Hi!")
print(f"Зашифровано: {secret}")  # Вывод: 1A 2A 4B 1A 2A 2A 4A

original = decrypt(secret)
print(f"Расшифровано: {original}")  # Вывод: Hi!
```

## ⚠️ Обработка ошибок
При попытке декодировать поврежденную строку скрипт выбросит понятное исключение `ValueError`:
* Если в строке есть неизвестные символы (разрешены только `A-H` и `1-8`, пробелы игнорируются).
* Если итоговое количество бит не делится на 8 (потерян или добавлен лишний символ шифра).
* Если бинарная последовательность не может быть декодирована в валидный символ UTF-8.
